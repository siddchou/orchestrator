# Novakai Orchestrator

Novakai Orchestrator is a job orchestration platform for multi-step workflows. It provides a web UI, REST API, and CLI for defining, scheduling, executing, and monitoring complex jobs composed of configurable steps.

## Technology Stack

| Layer | Technology |
|-------|------------|
| Backend | Java, Spring Boot |
| Frontend | [Frontend framework] |
| Database | H2 (development), PostgreSQL (production) |
| Build | Maven |
| Documentation | MkDocs with Material theme |
