# Step Types Reference

This page provides the configuration schema for each built-in step type with usage examples.

## ENV_SETUP

Schema and example configuration for environment setup steps, including variable injection and shell command execution.

## JAVA_EXEC

Schema and example configuration for Java executable steps, including classpath configuration, JVM arguments, and main class specification.

## SFTP

Schema and example configuration for SFTP transfer steps, including connection parameters, file paths, and credential references.

## LOG_CLEANUP

Schema and example configuration for log cleanup steps, including retention policies and file pattern matching.

## ARCHIVE

Schema and example configuration for archive creation steps, including compression format, source patterns, and destination settings.
