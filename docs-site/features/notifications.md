# Notifications

This page covers the notification subscription model, supported event types, channel configuration, and delivery logging.

## Subscription Model

How users or teams subscribe to notifications for specific jobs or run events (e.g., on failure, on completion).

## Event Types

A list of all notifiable events: job created, run started, run completed, run failed, schedule triggered, and others.

## Channel Configuration

How to configure notification channels, currently supporting Mail with SMTP settings, and how additional channel types can be added.

## Delivery Log

How to view the notification delivery log, including success/failure status, retry attempts, and recipient information.
