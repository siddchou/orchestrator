# Versions

This page covers job versioning, the version numbering scheme, label conventions, and the rollback procedure.

## Version Numbering

How versions are assigned to jobs (auto-incremented on each save), how to list all versions of a given job, and what metadata is stored per version.

## Label Convention

Best practices for labeling versions with human-readable descriptions (e.g., `v3 - added SFTP step`) to make rollback decisions easier.

## Rollback Procedure

Step-by-step instructions for rolling back a job to a previous version, including what happens to in-progress runs and how the version history is updated after a rollback.
