# Contributing

This page explains how to contribute to Novakai Orchestrator, including the fork-and-branch workflow, pull request checklist, and coding standards.

## Development Workflow

The standard contribution flow: fork the repository, create a feature branch, make changes, write tests, and submit a pull request.

## Build Instructions for Contributors

How to set up a local development environment, run the full test suite, and verify that your changes build cleanly before submitting a PR.

## Pull Request Checklist

Items to verify before opening a PR: tests pass, code formatting is applied, documentation is updated, and the commit message follows project conventions.

## Coding Standards

Java coding conventions, checkstyle rules, naming conventions, and any linting or formatting tools enforced by CI.
